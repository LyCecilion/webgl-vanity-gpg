webgl-vanity-gpg
源代码

本地运行的长期 GPG 密钥管理工具：在 GPU 上搜索创建时间落在指定范围、指纹以指定前缀开头的 Ed25519 主钥，之后可以继续为其追加签名／加密子钥、延长有效期，并导出只包含选定子钥秘密材料的设备私钥。

  • 请只在 localhost 使用本页面：它不加载任何外部图片或脚本，也不发送任何网络请求。
  • 浏览器不保存密钥、口令或设备映射；关闭页面后需要重新导入完整私钥备份才能继续管理。
  • 搜索命中后必须同时通过 GPU 与独立 CPU 的指纹校验，校验失败时会报错，不会签发任何密钥。
  • “靓号”原理参见：一位 PGP 进步青年的科学算号实践、某科学的 PGP 算号指南。使用 Rust 和 OpenCL 的本地算号工具见 opencl_vanity_gpg。
